# CodeGavel REST API

Base path: /api

## Authentication

POST /api/auth/register

POST /api/auth/login

## Problems

GET /api/problems

GET /api/problems/{id}

## Submissions

POST /api/submissions

GET /api/submissions/{id}

GET /api/submissions/me

## Status Codes

200 OK
201 Created
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
500 Internal Server Error
